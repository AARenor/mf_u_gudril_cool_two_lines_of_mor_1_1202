# u-gudril-cool-two-lines-of-morning-light-ade94fc5

A small program that writes one short text for make.fun's bounty `u-gudril-cool-two-lines-of-morning-light-ade94fc5`: a two-line micro poem about light and morning, entered into a pairwise AI-judged contest where the most beautiful poem wins.

The entry text:

```text

```

Run it with:

